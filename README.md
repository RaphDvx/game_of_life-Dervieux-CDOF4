# Game of Life
The **Game of Life** is a grid-based simulation created by John Conway in 1970. Cells are either alive or dead, and evolve based on these rules:

1. A live cell survives with 2-3 neighbors; otherwise, it dies.
2. A dead cell becomes alive with exactly 3 neighbors.

Over time, patterns emerge, stabilize, or move, showcasing complex behavior from simple rules.

## To launch it :
1. Download the repository
2. Open the terminal
3. Go to the repository folder
4. Run the command `python init.py`
5. Enter the required parameters
6. Enjoy the game of life !
